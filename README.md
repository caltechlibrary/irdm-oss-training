## Installation

This curriculum site is made using [zensical](https://zensical.org/docs/get-started/). The easiest way to install this locally is via `pip` (we recommend doing so inside of a virtual environment):

```sh
pip install zensical
```

Clone this repository via Git:

```sh
git clone git@github.com:caltechlibrary/irdm-oss-training.git
```

Then change directory to the newly cloned repository:

```sh
cd irdm-oss-training
```

From there, you can build the website with the following zensical command:

```sh
zensical build
```

There should be no errors, and if so you will be able to run the website to see locally:

```sh
zensical serve
```

Once that command runs, go to [http://localhost:8000](http://localhost:8000) in your Web browser.
